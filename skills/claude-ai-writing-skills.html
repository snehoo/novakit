What are Claude AI writing skills?

NovaKit writing skills are .skill files you download once and upload into Claude. Each one carries a specialist framework for a single writing job — a short story, a screenplay, a eulogy, a cover letter, an exam paper — so Claude stops behaving like a general assistant and starts behaving like someone who has written that thing a hundred times. Every skill runs live research on the format before it writes, asks three narrowing questions about your genre, audience and constraints, then runs a quality gate that rewrites weak passages before you ever see them.

This collection is for people whose output is words: novelists and self-publishers, screenwriters, teachers and tutors, academics, podcasters, job seekers, and anyone facing a speech they have to give on a fixed date. The outcome is a finished, specific draft on the first run — not a generic starting point you spend twenty minutes rescuing. Skills start at $5, work on a free Claude account, and cover 26 formats. If you write across several of them, the Creative Bundle collects six writing skills at a 41% saving.

Quick Answers

How do I get a NovaKit writing skill and install it?

After checkout you land on a delivery page with a download link for a .skill file, and the same link is emailed to you. In Claude, open Customize → Skills → +, choose Upload a skill, and drag the file in. It appears in your skills list immediately and runs as a slash command — type / in any new chat and pick it. The whole install takes under 60 seconds, and it works on both claude.ai and the Claude desktop app.

Do I need a paid Claude subscription?

No. Every writing skill on this page runs on a free Claude.ai account, with no API key and no third-party tool. A Claude Pro plan is worth having for the longest outputs — a full screenplay, a 12-section course curriculum, a complete children's book manuscript — because it allows longer responses, but nothing here requires it.

How is a skill different from a prompt I could write myself?

A prompt is a fixed instruction that ages the moment you save it. A NovaKit skill does three things a prompt cannot: it runs live research before writing, so a genre or format is assessed as it stands now rather than as it stood in training data; it interviews you with three narrowing questions so the output matches your brief; and it runs an anti-slop quality gate that rewrites clichéd or AI-tell phrasing internally before delivery. The Cover Letter Writer and University SOP skills both ship an explicit cliché audit for exactly this reason.

Which writing skill should I buy for my job?

Match the skill to the artefact, not the topic. Writing fiction: Short Story Prompt for structure, Screenplay / Script for a spec script, Children's Book Prompt for KDP picture books. Job hunting: Resume & CV Builder plus Cover Letter Writer. Teaching: Lesson Plan Builder and Exam Paper Generator. Speaking at an occasion: Event Speech Writer, Wedding Vows Writer, or Eulogy Writer.
